## Reddit Post (r/programming, r/devtools, r/commandline)

**Title:** [Release] Codra Code v0.2.3 — Local-first coding agent CLI with auth foundation and slash commands

**Body:**
We released Codra Code v0.2.3, adding auth foundation and slash commands to our local-first coding agent CLI.

What's new:
- Tera/Talocode auth foundation for future hosted usage
- Slash command picker with `/` key
- `/model` provider and model selector
- `/status` workspace/auth/model/mode display
- `/auth`, `/login`, `/logout` commands
- Hosted usage gating (local mode preserved)
- Improved terminal header and validation

Local-first mode remains available without auth using `codra-code --mock`. Hosted mode will require Tera/Talocode account when production auth ships.

Install:
```bash
npm install -g @talocode/codra-code@0.2.3
codra-code --help
```

Demo video and full release notes: https://github.com/talocode/codra

Feedback welcome!
