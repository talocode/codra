# Codra Local-First Skill

This skill emphasizes local-first principles for Codra projects.

## Principles

1. **Local-first data**: Store data locally by default
2. **Offline capability**: Ensure features work without internet
3. **User control**: Users own their data
4. **Privacy**: Never upload data without explicit consent
5. **Sync**: Optional sync as a secondary feature

## Implementation

- Use local storage for preferences
- Cache API responses locally
- Provide clear data export options
- Respect `.gitignore` for file operations
