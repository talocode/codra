## How to Apply These Topics

GitHub repository topics cannot be set programmatically from within the repository. You must add them manually:

1. Go to the repository on GitHub
2. Click the **⚙️** (gear) icon next to "Topics" on the right sidebar
3. Paste or type the topics listed above
4. Save changes

These topics help with discoverability and clearly signal that Codra is a serious, local-first AI coding agent built under the Talocode ecosystem.
