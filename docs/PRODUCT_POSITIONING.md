# Codra Product Positioning

## One-Liner

**Codra by Talocode** is a local-first AI coding agent for serious engineering.

## Target Users

- Professional software engineers and engineering teams
- Developers who want AI assistance without giving up control or privacy
- Teams building production software who need auditable, supervised agent workflows
- Users who prefer local-first tools and want to avoid cloud lock-in

## Main Problem

AI coding tools are powerful, but many workflows are cloud-dependent, fragmented, and hard to supervise across real projects. Developers often lose visibility, control, and context when using autonomous agents.

## Main Promise

Codra gives builders a local-first coding agent they can supervise, verify, and eventually control through Talocode — delivering real engineering value while maintaining full ownership of code, context, and execution.

## What Codra Is

- A local-first desktop coding agent runtime
- A supervised, repo-aware AI engineering assistant
- Part of the Talocode ecosystem for coding agents and developer automation
- Built with performance, security, and human oversight as core principles

## What Codra Is Not

- Not a generic chatbot or code completion tool
- Not a cloud-only coding assistant
- Not an unsafe autonomous agent that changes code without visibility or approval
- Not a replacement for your IDE or version control workflow
- Not a SaaS product that locks you into remote infrastructure

## How Codra Relates to Talocode

**Codra is the local agent.**  
**Talocode is the control plane.**

Codra handles all local execution, reasoning, file operations, and browser interaction. Talocode will provide the remote control layer, mobile access, team collaboration, audit logs, and orchestration across multiple Codra instances.
